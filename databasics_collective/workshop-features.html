Topics included in the workshop

This table shows how the source topics appear in the 90-minute Oracle Autonomous Database workshop.

Topic What is included in the workshop Where it appears
Introduction to Oracle Database Database and DBMS concepts, the difference between an instance and a database, schemas, SQL, common data models, and an introduction to Autonomous Database. Introduction and Lab 1
Database overview and architecture Instance memory, background processes, database services, CDBs, PDBs, schemas, the managed-service boundary, and basic data dictionary queries. Lab 1
Schemas, relationships, and constraints Redundancy, normalization, primary and foreign keys, unique and check constraints, one-to-one, one-to-many, and many-to-many relationships with a junction table. Lab 2
Create and manage data structures DDL, CREATE TABLE, common data types, default values, constraints, ALTER TABLE, adding and dropping a temporary column, auto-commit behavior, and dictionary inspection. Lab 3
Select, insert, update, and delete data Core DML, filters, joins, aggregation, safe predicates, COMMIT, ROLLBACK, row locks, consistent reads, and the purpose of MERGE. Lab 4
Schema objects Tables, regular and materialized views, sequences, private and public synonyms, and how these objects support access to the university schema. Lab 5
Database deployment options Autonomous Database as the workshop environment, with a concise comparison of on-premises systems, Exadata, Cloud@Customer, and Oracle cloud database services. Lab 1
Indexes in Oracle Database Index purpose, B-tree indexes, foreign-key indexes, optimizer choice, and beginner context for bitmap, function-based, specialized, and automatic indexes. Lab 5
